      Warehouse Management API

      Set up warehouses, shelf locations and cartons, then receive stock at the dock, move it between shelves and look up where everything is. Every endpoint can be run against the live server, and the floor view shows each request travelling through the building.

      Signing in

      1. Create an account with POST /users. New accounts get the USER role.
      2. Sign in with POST /auth/login. You get an access token that lasts about 15 minutes and a refresh token that lasts about 7 days.
      3. Send Authorization: Bearer <accessToken> with every protected call. When it expires, swap the refresh token for a new pair at POST /auth/refresh.

      When a call fails

      400The request is invalid. Field errors come back as {"field": "message"}, broken business rules as {"error": "…"}.
      401No token, or it has expired. Sign in again or refresh.
      403Your account doesn't have the ADMIN role.
      404Something the request refers to doesn't exist.
      409A duplicate, an SSCC that was already received, or someone else saved the record first. Reload and try again.
